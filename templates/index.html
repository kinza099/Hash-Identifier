info How it works & Accuracy Considerations

This tool performs evidence-based structural analysis across length, character set (Hex, Base64, MCF), and prefix/format signatures (e.g. $2b$ for bcrypt, $argon2id$ for Argon2, * for MySQL 4.1+).

Accuracy Notice: A hash string alone often cannot uniquely identify its algorithm when multiple algorithms share the same length (e.g., MD5 and NTLM are both 32 hex chars). Format matches indicate structural compatibility rather than definitive cryptographic proof. Ambiguity notices are shown whenever multiple algorithms are viable.

info Input Encoding & Security Notice
Input strings are encoded using canonical UTF-8 bytes. Empty text explicitly produces the official standard 0-byte digest for each algorithm (e.g. MD5 d41d8cd98f00b204e9800998ecf8427e). MD5 and SHA-1 outputs are provided for legacy/educational purposes and are not recommended for security-critical integrity verification.
