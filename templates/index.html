ℹ️ How it works

This tool analyzes the length, character set, and known prefix patterns (like $2b$ for bcrypt or $argon2id$ for Argon2) of your input to narrow down which hashing algorithm(s) could have produced it. Many hash types share the same output length (e.g. MD5 and NTLM are both 32 hex characters), so multiple possible matches may be shown — this is normal and expected since hash identification by pattern alone cannot always be 100% certain.
